# Repository guidance

CLUB DYNASTY is an offline-first Portuguese football management game, not a marketing website. Read PRODUCT.md and DESIGN.md before editing UI. Impeccable's official skill is at .agents/skills/impeccable/SKILL.md.

Apply clarify, distill, audit and polish:
- Do not invent features or marketing copy.
- Prioritize game state, meaningful actions and authentic limitations.
- Avoid slogans, eyebrow headings, decorative indexes, glowing rings and nested cards.
- Preserve data-action, data-nav, saves, engine modules and browser tests.
- Run npm run check, npm test, npm run design:audit and browser QA before shipping.
