# NEON INFINITE

A browser-first infinite 3D city explorer. Original game inspired by the **idea** of GigaCity: deterministic endless procedural generation. This is a separate, independently written implementation, not a copy of its code/assets.

![Desktop/Android](https://img.shields.io/badge/platform-Desktop%20%7C%20Android-fd6751) ![Three.js](https://img.shields.io/badge/3D-Three.js-e6e6e6) ![No build step](https://img.shields.io/badge/build-None-76cdab)

## Features

- City generated by seeded deterministic chunks, streamed around the camera
- SSS Tier visual world: seven skyscraper profiles, stepped towers, podiums, rooftop structures, antennas, crowns, sky gardens, helipads, illuminated accents and procedural facade windows
- City roads with lane dividers, curbs, crossing markings, raised sidewalk plots and dense streetlights
- Animated traffic with multi-part cars, cabins, headlamps and tail lamps; parks with trees and pavilions
- Cinematic sun sphere, clear blue daylight, daylight fog and adaptive day/night lighting, plus optional rain
- Fly in 3D (keyboard + mouse on desktop, joystick + look gestures on Android)
- Collect airborne signals, earn points and multipliers, save automatically in `localStorage`
- Day/night toggle (day is now the default), rain toggle, performance mode, screenshot PNG, radar minimap, pause and help menu
- Automatic GitHub Pages deployment, syntax checks, unit tests
- No account, ads, backend, analytics or paid services

## Play

In your browser on a laptop/PC or Android device. Chrome/Edge with WebGL recommended.

| Desktop | Android |
|---|---|
| WASD / arrows: move | Left joystick: move |
| Mouse: look (click 3D canvas to lock pointer; Esc to release) | Swipe right area: look |
| Space or Q: fly up | ↑: fly up |
| E or Ctrl: fly down | ↓: fly down |
| Shift: turbo | ⚡: turbo |
| Mouse wheel: change speed | Use turbo to travel faster |
| N: day/night, P: pause, H: help | UI buttons |

Fly within 16 meters of the glowing red signal to collect it. A signal will be generated in many of the city's chunks.

## Run locally

This is a **static site** using ES modules, so you don't need npm dependencies or a bundler. It loads Three.js v0.180.0 from jsDelivr; therefore, the first run requires an internet connection. Do not open `index.html` as a `file://` URL because of browser module restrictions. Serve the folder locally:

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

Tests need Node 22+, but not `npm install`:

```bash
npm run check
npm test
```

## Publish with GitHub Pages

1. Create a **public** repository, for example `PulseBreakPT/NeonInfiniteCity`, with an initial `README.md` or an empty repository.
2. Push **all** project files, including `.github/workflows/pages.yml`, to the `main` branch.
3. Open **Settings → Pages** and select **GitHub Actions** as the source (if needed).
4. Open **Actions → Deploy NEON INFINITE to GitHub Pages** and verify that the deployment passed.
5. The published address will be `https://pulsebreakpt.github.io/NeonInfiniteCity/` if you use that exact owner/repository name.

The included workflow validates JavaScript + tests and deploys the static site on each push to `main`.

## Architecture

- `src/world/procedural.js`: pure deterministic world model. `BLOCK=64m`, 4×4 blocks per chunk.
- `src/world/CityWorld.js`: Three.js instanced meshes, shader-based windows, roads, cars, beacons and streaming lifecycle.
- `src/engine/FlightControls.js`: free-flight input with mouse/touch joystick.
- `src/engine/Atmosphere.js`: lighting, fog and rain.
- `src/game/save.js`: defensively parsed local save data.
- `src/main.js`: game loop, score, missions, minimap, UI and settings.
- `tests/procedural.test.js`: pure generator tests.

## Performance and limitations

Low-performance mode keeps 3×3 chunks active; desktop high-detail mode keeps 7×7. The world is infinite by generating new terrain as you move, not by keeping the entire world in RAM. This is an atmospheric exploration prototype: it does **not** offer detailed vehicle physics, ground collision or enterable buildings. Uses WebGL, not WebGPU. Three.js is loaded from a third-party CDN; this project is not fully offline without vendoring that dependency.
