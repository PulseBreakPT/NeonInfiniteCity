# PREMIUM500 · Último Abrigo

500 SVGs vetoriais isométricos originais em `items/` (`p000.svg` a `p499.svg`), dez atlas SVG de 50 sprites cada em `atlases/`, `manifest.json` e uma galeria visual pesquisável (`gallery.html`).

**Contagens:** terreno 120, natureza 120, arquitetura 60, interior 65, veículos 35, urbano 45, sobrevivência 35 e personagens 20. Variações procedimentais de cor, pormenor e forma dentro de cada família. Cada sprite individual é 128 × 128, com fundo transparente. Os atlas têm 10 colunas × 5 linhas.

Criado para Vale Sereno. Arte original independente de Project Zomboid, sem dependências externas.
